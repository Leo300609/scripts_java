# ☕ Variáveis em Java

Um repositório prático para estudos e demonstração dos conceitos fundamentais de **variáveis, tipos de dados e operadores na linguagem Java**.

---

## 📌 Sobre o Projeto

Este projeto consiste em um ambiente de aprendizado em Java utilizando Maven (`demo`), focado em exemplificar, testar e fixar o funcionamento de variáveis.

### 📑 Conteúdo Abordado
* **Tipos Primitivos:** `int`, `double`, `float`, `boolean`, `char`, `byte`, `short`, `long`.
* **Tipos Não-Primitivos / Referência:** `String` e classes wrappers.
* **Declaração e Inicialização:** Atribuição de valores e boas práticas de convenção (`camelCase`).
* **Escopo de Variáveis:** Variáveis locais e de classe.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** [Java](https://www.oracle.com/java/) (JDK 17+)
* **Gerenciador de Dependências:** [Apache Maven](https://maven.apache.org/)
* **IDE Recomendada:** [Visual Studio Code](https://code.visualstudio.com/) ou [IntelliJ IDEA](https://www.jetbrains.com/idea/)
